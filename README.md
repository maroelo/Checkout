# Funcionalidades
- Carrinho com leitura de código de barras
  - produtos podem ser adicionados manualmente ou pela leitura do código de barras.

- Promoções
  - Tela inicial alimentada por API com os produtos em oferta, que podem ir direto para o carrinho ou para uma lista criada pelo usuário.

- Listas de compras
  - Criar, renomear e excluir listas e gerenciar os produtos de cada uma.

- Configurações
  - Métodos de pagamento e histórico de compras.

# Tecnologias utilizadas
Flutter / Dart - Desenvolvimento do aplicativo
SQLite - armazenamento local
Figma - design das telas

Arquitetura
Aplicação modular, com telas independentes acessadas por uma barra de navegação inferior. Cada funcionalidade é implementada em classes dedicadas, separando responsabilidades e facilitando a reutilização de código.

Como executar
bash
flutter pub get
flutter run
